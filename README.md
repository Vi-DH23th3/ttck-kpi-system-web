# KPI Management System

## Overview

KPI Management System is a web-based application developed for the
Center of Information Technology and Foreign Languages – An Giang University.

The system supports KPI management, KPI assignment, work progress reporting,
approval workflows, user management, and role-based access control.

## Technologies

- PHP / Laravel
- MySQL
- HTML / CSS
- JavaScript
- Bootstrap

## Main Features

- User and role management
- KPI management
- KPI assignment
- Work progress reporting
- KPI report approval and rejection
- Notifications
- Authentication
- Google Login
- Role-based access control
